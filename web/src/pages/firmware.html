C2000 port layer (monitor-only)

The control interrupt calls gm_port_push() once per sample: calibration trim (mandatory), optional line-to-neutral to line-to-line conversion, a polyphase anti-alias filter and decimation to 5 kHz into a {{port.port_struct_bytes|int}}-byte structure that includes a 1.6 s ring buffer. A background task triggers, places a 1 s record around the estimated onset, classifies it and publishes telemetry. It never writes a control variable.

Integration notes

  • TIDA-01606 (three-phase, 50 kHz control ISR): one gm_port_push() call after the control law; decimation by 10; LN or LL sensing selectable (which one the board uses is still to be confirmed from TI's SDK source); per-channel calibration trim is mandatory because the rules are calibration-sensitive; background processing in the main loop or on CPU2.
  • TIDM-HV-1PH-DCAC (single-phase): one board sees one phase, so the three-phase features do not exist there. For three boards 120° apart, run this unchanged three-phase core on a separate monitor node (for example a LaunchPad with isolated line-to-neutral sensing of all three phases), independent of the inverter controllers. A single-phase variant is Stage 2.
  • Safety: both reference designs are high-voltage hardware (800 V and 380 V DC). Board work only under qualified supervision, with isolated debug connections, and only after the LaunchPad steps (L3, L4) have passed. The module stays monitor-only until separately validated.
